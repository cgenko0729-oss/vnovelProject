# ============================================================
# PhotoDemo.vn.txt —— 拍大头照小游戏演示
# 示范：① 自由拍照（不评分）② 带主题评分的正式拍摄 ③ 靠分数 flag 做细分支
#       ④ 换主题重拍 ⑤ 分数自动换算成属性
# 播放方式：Scenario Editor 打开本文件 → 选中首行 → ▶ 从选中行播放
# 装机：Tools → VN Effects → Install Photo Booth Module To Scene（只装一次，可重复执行）
# 资产：Assets/VNEffects/Photo/{Frames,Stickers,Themes}
# 操作：左栏选边框/贴纸　右栏点表情　左键拖贴纸　滚轮缩放　Shift+滚轮旋转
#       右键删贴纸　◉ 快门　ESC 放弃（会弹确认）
# 注意：vs: / me: 的角色必须登记在 VNGameConfig 的角色库里，否则运行时找不到人
# ============================================================

: （放学路上，商店街拐角那台大头贴机还亮着灯。）

# ---------- ① 自由拍照：不写 theme: 就是随便拍，只返回「完成」 ----------

label 试机器
: 星野结衣「先试一张？反正不要钱。」
event photo vs:星野结衣 me:川岛葵 mode:free
* 完成

: （照片存进相册了。）

# ---------- ② 正式拍摄：写了 theme: 就按主题评分，三档结果 ----------
# 主题资产列出这个主题想要什么表情/边框/贴纸，命中就加分。
# time: 覆盖主题自带的限时；stat:/rate: 让分数自动换算成属性
#   （加成 = 分数 × rate，走 VNStatsHud 的飘字演出）。

label 正式来一张
: 星野结衣「这次认真拍。要甜一点的那种。」
event photo vs:星野结衣 me:川岛葵 theme:甜蜜 frame:粉格子 time:60 stat:魅力 rate:0.1
* 完美 -> 拍得真好
* 普通 -> 还行吧
* 失败 -> 拍砸了

# ---------- ③ 靠成绩 flag 做细分支 ----------
# 模块结束会写三个 flag（前缀默认「大头照」，剧本 flag: 可改）：
#   大头照_分数 / 大头照_档位（2 完美 1 普通 0 失败）/ 大头照_次数

label 拍得真好
flag 回忆 +1
: 星野结衣「哇……这张真的可以。」
if 大头照_分数 >= 90 jump 满分照
: 星野结衣「存好了啊，别弄丢。」
jump 换个主题

label 满分照
: 星野结衣「这张……能给我也发一份吗？」
flag 好感 +2
jump 换个主题

label 还行吧
: 星野结衣「嗯……还行。表情有点僵。」
jump 换个主题

label 拍砸了
: 星野结衣「……这什么啊，重拍重拍。」
: （其实结算画面上就有「重拍」按钮，当时就能重来。）
jump 换个主题

# ---------- ④ 换主题再来一张 ----------

label 换个主题
choice
* 拍张搞怪的 -> 搞怪场
* 拍张青春的 -> 青春场
* 今天就到这 -> 结束

label 搞怪场
: 星野结衣「这次别正经，越夸张越好。」
event photo vs:星野结衣 me:川岛葵 theme:搞怪 frame:胶片
* 完美 -> 笑疯了
* 普通 -> 换个主题
* 失败 -> 换个主题

label 笑疯了
: 星野结衣「哈哈哈哈这什么表情——」
flag 好感 +1
jump 换个主题

label 青春场
: 星野结衣「那……拍张正常的吧。留个纪念。」
event photo vs:星野结衣 me:川岛葵 theme:青春 frame:简约白框
* 完美 -> 好照片
* 普通 -> 换个主题
* 失败 -> 换个主题

label 好照片
: 星野结衣「……多年以后翻出来，会记得今天吧。」
flag 回忆 +2
jump 换个主题

label 结束
: （今天的照片都存进相册了。）
: 星野结衣「走吧，天要黑了。」
