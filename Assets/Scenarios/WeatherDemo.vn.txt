# ============================================================
# WeatherDemo.vn.txt —— 飘落天气演示（落樱 / 落叶 / 秋叶）
# 示范：① 五种叶型 ② 四个覆盖参数 ③ 与 mood 的搭配 ④ 樱吹雪
# 播放方式：Scenario Editor 打开本文件 → 选中首行 → ▶ 从选中行播放
#
# 看什么：
#   花瓣是**有颜色的实体**，会挡住背景（不再是被 Bloom 洗白的光点）
#   每片形状不同，而且在**绕自身长轴翻转**（宽度会呼吸、背面更暗）
#   相邻的花瓣**各飘各的**，不会集体同步摆动
#   隔一会儿会自动刮**一阵风**，整屏斜掠过去再回到缓飘
#   远景小而淡、近景大而虚焦 —— 三层景深
#
# 调参：Tools → VN Effects → Weather Preview
# ============================================================

bg 天台
mood Neutral

# ---------- ① 落樱 ----------

weather petals
: （落樱。轻、慢，幅度大频率低地飘。注意花瓣是**粉的**，不是白的。）
: （盯住某一片看：它在翻转 —— 转到侧面时会收窄成一条线，背面明显更暗。）
: （再等一会儿：会自动刮一阵风，整屏花瓣一起斜掠出去。）

: （加大密度、加强风力：）
weather petals density:18 wind:-1.2
: （同一套参数，剧本里随时可以覆盖。）

# ---------- ② 秋枫 ----------

weather maple
: （枫叶。比花瓣**重**：落得快、翻得凶、摆幅小但频率高。）
: （颜色是从红到橙到黄到褐随机取的 —— 秋天的味道主要来自这个色差，不是叶子的轮廓。）
: （飘到画面下缘的叶子会**堆在地上**再慢慢淡出，不是凭空消失。）

# ---------- ③ 银杏 ----------

weather ginkgo
: （银杏。金黄扇形，打旋比枫叶更明显。）

# ---------- ④ 阔叶 / 竹叶 ----------

weather leaves
: （普通阔叶。初秋的绿黄混杂到深秋的褐色。）

weather bamboo size:1.3
: （竹叶 / 柳叶。细长轻盈，飘忽不定。）

# ---------- ⑤ 中文 id 也认 ----------

weather 落樱
: （内置叶型认中文别名：落樱 / 枫叶 / 银杏 / 落叶 / 竹叶。）

# ---------- ⑥ 樱吹雪 ----------

: （最后来一发樱吹雪：起手一记强阵风，近景大瓣贴着镜头横掠。）
sakura

weather None
: （演示结束。）
