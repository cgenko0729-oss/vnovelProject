# ============================================================
# QuizDemo.vn.txt —— 限时问答模块演示
# 示范：① 随机抽题的三档结果 ② pick 指定题号 ③ 成绩 flag 细分与属性联动
# 播放方式：Scenario Editor 打开本文件 → 选中首行 → ▶ 从选中行播放；
#           或把 VNScriptRunner 的剧本换成本文件。
# 答题操作：点选项或按 1 / 2 / 3 / 4；每题限时结束即算答错
# 题库：Assets/VNEffects/Quizzes/社团常识.asset（Inspector 里加题即可）
# ============================================================

: （社团招新前的小测验。答对涨智力，答错涨压力——题库资产里逐题配好了。）

# ---------- ① 随机抽 3 题，及格线 2 题 ----------

label 入社测验
event quiz id:社团常识 count:3 time:15 pass:2
* 全对 -> 满分
* 及格 -> 及格
* 失败 -> 不及格

label 满分
flag 社团评价 +2
: （全部答对！学姐眼睛都亮了。「你该不会早就调查过我们社团吧？」）
jump 复试

label 及格
flag 社团评价 +1
: （勉强及格。「基础还行，剩下的进来慢慢学。」）
jump 复试

label 不及格
: （惨不忍睹。「……你确定你要加入的是我们社？」）
jump 收尾

# ---------- ② pick 指定题号：复试固定考这两题 ----------

label 复试
: （「既然这样，再来两道正式的。」学姐翻开了本子。）
event quiz id:社团常识 count:2 time:10 pass:1 pick:3,4 title:社团规章复试 flag:复试
* 全对 -> 复试满分
* 及格 -> 复试及格
* 失败 -> 复试失败

label 复试满分
flag 社团评价 +2
: （两题全中。「规章背得比我还熟。」）
jump 收尾

label 复试及格
: （对了一题。「……算你过关。」）
jump 收尾

label 复试失败
: （全错。「回去把社团手册读三遍。」）
jump 收尾

# ---------- ③ 用成绩 flag 做更细的分支 ----------
# 模块会写入 <前缀>正确数 / <前缀>总数（前缀默认取题库的 flagPrefix，剧本 flag: 可覆盖）

label 收尾
if 答题正确数>=3 jump 学霸称号
if 社团评价>=3 jump 优等生
: （测验结束。成绩记在了 flag 里——先当个普通新人吧。）
jump 结束

label 学霸称号
: （初试全对的成绩记在了社团名册上。「学霸来了！」）
jump 结束

label 优等生
: （综合表现优秀，学姐当场递来了入社申请表。）

label 结束
: （QuizDemo 播放完毕。随机抽题 / 指定题号 / 三档结果 / 成绩 flag 都看过了。）
