# ============================================================
# FogWipeDemo.vn.txt —— 擦雾小游戏演示
# 示范：① 起雾盖住 CG，按住左键擦开 ② 雾会重新凝结，要跟它赛跑
# 播放方式：Scenario Editor 打开本文件 → 选中首行 → ▶ 从选中行播放
# 操作：按住鼠标左键在画面上拖动 = 擦拭；ESC 放弃（按当前成绩判档）
# ★ 用 cg: 参数指定要擦的图，**不要**在 event 之前先写 cg ——
#   模块要到事件启动才铺得出雾，先写 cg 的话清晰画面会先摆在玩家眼前，
#   谜底在开始擦之前就揭晓了。交给模块自己铺，第一帧就是盖满雾的状态。
#   事件结束后再写 cg，画面才留在舞台上继续演剧情（同一帧交接，不会闪）。
# 参数：time: 时限秒 / target: 「普通」门槛% / perfect: 「完美」门槛%
# 资产：Assets/VNEffects/FogWipes/浴室镜面.asset（雾外观 / 回雾 / 阶段台词）
#       调参走 Tools → VN Effects → 预览 Preview → 擦雾调参 Fog Wipe Tuning
# 装机：Tools → VN Effects → 场景装机 Install To Scene → 擦雾 Fog Wipe
# ============================================================

bg test1
: 浴室的门没关严，镜子上蒙了一层白雾。
: （什么都看不清……擦一擦吧。）

# 擦雾：cg: 指定要擦的图，进事件的第一帧就是盖满雾的状态
event wipefog id:浴室镜面 cg:CG_test time:60 target:65 perfect:90 stat:感性 rate:0.08 flag:擦雾1
* 完美 -> 完美
* 普通 -> 普通
* 失败 -> 失败

# ---------- 三条结果分支 ----------

# 事件结束后自己把 CG 摆到舞台上，画面才留得住继续演
# （模块销毁与这条 cg 在同一帧交接，不会闪）
label 完美
cg CG_test
星野结衣 害羞: ……看这么清楚做什么啦。
: （擦得很干净。她的表情一览无余。）
jump 收尾

label 普通
cg CG_test
星野结衣: 好啦好啦，看也看够了吧。
: （勉强看清了个大概。）
jump 收尾

# 失败分支故意不写 cg —— 剧情上就是没看清，画面回到背景才对
label 失败
: 雾又聚拢起来，什么都看不清了。
星野结衣: ……走开。
jump 收尾

label 收尾
# 这里不写 cg off —— 失败分支本来就没显示 CG，无脑 off 会打一条
# 「cg off 时没有显示中的 CG」的警告
# 成绩写在 flag 里，可以再细分：
#   擦雾1_清晰度（0~100）/ 擦雾1_用时（秒）/ 擦雾1_档位（2 完美 / 1 普通 / 0 失败）
# if 只支持 jump 形式，想按成绩加戏就跳一个小标签
if 擦雾1_清晰度>=95 jump 擦得真干净
: —— 演示结束 ——
jump 结束

label 擦得真干净
: （连镜角的水痕都擦掉了。）
: —— 演示结束 ——

label 结束
