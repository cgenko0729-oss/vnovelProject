# ============================================================
# BadmintonDemo.vn.txt —— 羽毛球小游戏演示
# 示范：① 自由练习（无胜负）② 属性联动的正式赛 ③ 靠比分 flag 做细分支 ④ 换难度重赛
# 播放方式：Scenario Editor 打开本文件 → 选中首行 → ▶ 从选中行播放
# 装机：Tools → VN Effects → Install Badminton Module To Scene（只装一次，可重复执行）
# 对手资产：Assets/VNEffects/Badminton/{新手,校队,王牌}.asset
# 操作：A/D 移动　J 击球（兼发球）　K 起跳扣杀　ESC 认输（正式赛会弹确认）
# ============================================================

: （放学后的体育馆，球拍在手里转了半圈。）

# ---------- ① 自由练习：没有胜负，ESC 随时收工 ----------

label 热身
: （先随便打两下找找手感吧。）
event badminton vs:小雪 id:新手 mode:free
* 结束

: （手感差不多了。）

# ---------- ② 正式赛：能力读养成属性 ----------
# powerstat / speedstat / jumpstat 指定从哪个 flag 读属性；
# 属性越高，扣杀力度、移动速度、跳跃高度越高（每点增量配在 Def 资产里，上限 statCap）。
# 剧本先 stat 练体育，羽球自动变强——桥全在 flags 上，模块不认识任何具体属性名。

label 校队选拔
stat 体育 +3
: 小雪「热身够了吧？来真的。」
event badminton vs:小雪 id:校队 target:5 powerstat:体育 speedstat:体育 jumpstat:体育
* 胜利 -> 赢了校队
* 失败 -> 输给校队

# ---------- ③ 靠比分 flag 做细分支 ----------
# 模块结束会写四个 flag（前缀默认「羽球」，剧本 flag: 可改）：
#   羽球_我方得分 / 羽球_对方得分 / 羽球_精准数 / 羽球_最长回合

label 赢了校队
flag 社团评价 +2
: 小雪「……可以啊你。」
if 羽球_对方得分 == 0 jump 零封
if 羽球_精准数 >= 3 jump 打得漂亮
: （赢下来了，虽然过程有点狼狈。）
jump 挑战王牌

label 零封
flag 社团评价 +2
: 小雪「一分都没让我拿到？你以前是不是打过？」
jump 挑战王牌

label 打得漂亮
: 小雪「你那几个甜区击球……教练看到会哭的。」
jump 挑战王牌

label 输给校队
: 小雪「差得还远呢。」
# 虽败犹荣：只差一分也算表现不错
if 羽球_对方得分 - 羽球_我方得分 <= 1 jump 惜败
: （被打得毫无还手之力。）
jump 收尾

label 惜败
flag 社团评价 +1
: 小雪「不过……最后那几球，你有点吓到我了。」
jump 收尾

# ---------- ④ 换难度重赛：同一个模块，换 id 就是换对手 ----------

label 挑战王牌
choice
* 去挑战县大赛冠军 -> 打王牌
* 今天就到这里 -> 收尾

label 打王牌
: （传说中的那个人就站在对面网前。）
event badminton vs:学姐 id:王牌 target:7 powerstat:体育 speedstat:体育 jumpstat:体育 flag:决赛
* 胜利 -> 爆冷
* 失败 -> 惨败

label 爆冷
flag 社团评价 +5
: 学姐「……你叫什么名字？」
jump 收尾

label 惨败
: 学姐「基本功不错。明年再来。」
: （记分板上是 决赛_我方得分 分。差距很清楚。）
jump 收尾

label 收尾
: （把球拍收进袋子，体育馆的灯一盏盏灭了。）
