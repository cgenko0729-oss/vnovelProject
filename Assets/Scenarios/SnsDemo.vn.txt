# ============================================================
# SnsDemo.vn.txt —— 手机聊天（SNS）演示
# 示范：① 打开/关闭聊天界面 ② 文字/语音/图片消息 ③ 正在输入…与已读
#       ④ 限时回复（超时 = 已读不回）⑤ 聊天里也能用 flag / if 分支
# 播放方式：Scenario Editor 打开本文件 → 选中首行 → ▶ 从选中行播放
#
# 核心概念：sns open 之后，**普通台词行**就是聊天气泡——
#   「星野结衣: 内容」= 左侧对方气泡
#   「我: 内容」      = 右侧自己气泡（me / 我 / 玩家 / 主角 都算自己，
#                        也可以用 sns open 的 me: 参数指定别的名字）
#   「: 内容」        = 居中系统提示（无名牌旁白）
# 操作：点手机空白处推进；点语音气泡播放；点图片气泡看大图；
#       聊天期间 H/滚轮回想、A/S 自动快进被屏蔽，F5/F9/Q/L 存读档照常可用
# ============================================================

: （手机震了一下。是星野结衣发来的消息。）

sns open 星野结衣 title:星野结衣 me:我
sns time 今天 21:34

星野结衣: 在吗？
星野结衣: 刚才社团活动室…你是不是把伞落下了

sns typing 1.6
星野结衣: 我先帮你收着了

sns image 星野结衣 CG_雨伞 unlock:yes
星野结衣: 喏，就是这把吧

我: 啊，真的是我的
sns read

# ---------- 限时回复：8 秒内不选就是「已读不回」 ----------

sns typing 1.2
星野结衣: 那…明天早点来拿？

sns reply timeout:8 late:没回复 lateflag:好感度-1
* 好，明天见 flag:好感度+2 -> 答应了
* 你直接带来给我吧 flag:好感度-1 -> 使唤她
* 其实那不是我的伞 -> 装傻

# ---------- 各回复的后续 ----------

label 答应了
sns typing 1.4
星野结衣: 嗯，那我在活动室等你
# 语音气泡：点击播放。语音 id 要在 VNGameConfig 的 Voice Library 里登记，
# 没登记时气泡照样出现、点击只是没有声音。
sns voice 星野结衣 voice1 text:语音·点击播放
: （她还发了条语音。点开听听。）
星野结衣: 晚安啦
jump 收尾

label 使唤她
sns typing 2
星野结衣: ……
星野结衣: 我明天要值日，没空绕路
: （气氛有点僵。）
jump 收尾

label 装傻
sns typing 1.8
星野结衣: 伞柄上写着你的名字哦
我: ……
星野结衣: 明天记得来拿
jump 收尾

label 没回复
sns system 你没有点开回复，就这样把手机扣在了桌上。
sns typing 2.4
星野结衣: 睡了吗？那明天再说吧
jump 收尾

# ---------- 收尾：关掉手机回到普通对话 ----------

label 收尾
sns time 今天 21:52
星野结衣: 晚安
sns close

: （放下手机，房间安静下来。）

if 好感度 >= 2 jump 心情好
: （明天得早点起了。）
jump 结束

label 心情好
: （不知道为什么，有点期待明天。）

label 结束
: —— SNS 演示结束 ——
