# ============================================================
# InteractionDemo.vn.txt —— 亲密互动小游戏演示
# 示范：① 光标变道具、点/摸角色部位推进阶段 ② 禁忌部位与拒绝失败
# 播放方式：Scenario Editor 打开本文件 → 选中首行 → ▶ 从选中行播放
# 操作：按住左键在角色身上来回移动 = 抚摸；单击也算一点点
#       zones:on 会把部位框画出来（开发调试用，正式剧本删掉这个参数）
# 资产：Assets/Art/VNEffects/TouchZones/星野结衣.asset（部位框）
#       Assets/Art/VNEffects/Interactions/初次抚摸.asset（阶段与反馈）
# 装机：Tools → VN Effects → 场景装机 Install To Scene → 亲密互动 Interaction Module
# ============================================================

bg test1
show 星野结衣 at:center expr:默认 with:StepIn
ui dialogue 黑渐变
event badminton tutorial:羽毛球基础
星野结衣 inter: 今天……只有我们两个人呢。
: （试着摸摸看吧。按住左键在她身上移动。）
interlude 01 time:3

# event 前必须先 show 角色 —— 模块只换表情，不负责让人出场
event interact vs:星野结衣 id:初次抚摸 zones:on
* 满足 -> 满足
* 普通 -> 普通
* 拒绝 -> 拒绝

# ---------- 三条结果分支 ----------

label 满足
星野结衣 害羞: ……笨蛋。谁准你这样了。
: （但她没有推开我。）
jump 收尾

label 普通
星野结衣 微笑: 嗯……今天就到这里吧。
jump 收尾

label 拒绝
星野结衣 生气: 我说了，现在还不行。
: （做得太过火了。）
jump 收尾

label 收尾
# 成绩写在 flag 里（抚摸_阶段 / 抚摸_兴奋度 / 抚摸_拒绝数 / 抚摸_<部位>次数）；
# 台词不支持变量插值，要用成绩就写 if 分支
if 抚摸_阶段 >= 3 jump 走得太远
jump 结束

label 走得太远
: （……好像，稍微走得有点远了。）

label 结束
hide 星野结衣
: —— 演示结束 ——
