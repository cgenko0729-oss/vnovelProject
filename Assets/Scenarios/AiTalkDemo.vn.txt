# ============================================================
# AiTalkDemo.vn.txt —— AI 自由聊天模块演示
# 示范：① 最小用法 ② 属性联动与成绩 flag ③ 四个结果分支 ④ 断网兜底
# 播放方式：Scenario Editor 打开本文件 → 选中首行 → ▶ 从选中行播放；
#           或把 VNScriptRunner 的剧本换成本文件。
#
# 装机：Tools → VN Effects → Install AI Talk Module To Scene（只需一次）
# 人格：Assets/Art/VNEffects/AiPersonas/星野结衣_日常.asset（Inspector 里调性格）
# Key ：环境变量 GEMINI_API_KEY 或 GeminiAiApiKey.txt
#       没配 key 也能跑——每轮走人格资产里的兜底台词，结果返回「失败」
#
# 【玩法定位】本模式只用在番外 / 自由时间，主线剧情不依赖它。
#             理由：AI 生成的内容不进翻译表、没有配音，且玩家可能断网。
# ============================================================

: （放学后。教室里只剩下你和还在收拾书包的她。）

show 星野结衣 at:center

# ---------- ① 最小用法：只写 vs，其余全用人格资产的默认值 ----------
# persona: 省略时按 vs 的角色 id 自动找该角色的人格

event aitalk vs:星野结衣 turns:6 topic:随便聊聊今天发生的事 place:放学后的空教室 stat:好感 rate:2 flag:闲聊_
* 好感提升 -> 聊得不错
* 普通 -> 平淡收场
* 冷场 -> 气氛尴尬
* 失败 -> 连不上

# ---------- ② 按结果分支 ----------

label 聊得不错
星野结衣 微笑: 今天……聊得挺开心的。
: （好感涨了。模块把变化量 ×2 加进了「好感」。）
jump 看成绩

label 平淡收场
星野结衣 默认: 那个，我该回去了。
: （不好也不坏，就是普通的一天。）
jump 看成绩

label 气氛尴尬
星野结衣 沮丧: ……我先走了。
: （似乎说错了什么。）
jump 看成绩

# ---------- ③ 断网 / 没配 key / 被内容安全拦下 ----------
# ★ 这个分支必须写，否则玩家断网时剧情会像什么都没发生一样往下跑
#   （Lint 规则 aitalk-no-failure-branch 会检查）

label 连不上
: （她好像在想别的事情，一直没有开口。）
: （——AI 服务没连上。检查网络，或用 Tools → VN Effects → AI → Show Key Status 看 key。）
jump 结束

# ---------- ④ 用成绩 flag 做更细的分支 ----------
# 模块写入：<前缀>轮数 / <前缀>好感变化 / <前缀>倾向_温柔 / _玩笑 / _直球

label 看成绩
if 闲聊_倾向_直球>=3 jump 太直接了
if 闲聊_倾向_玩笑>=3 jump 一直在开玩笑
: （这次的对话记在心里了。）
jump 结束

label 太直接了
星野结衣 害羞: 你今天……说话怎么老是那么直接啊。
jump 结束

label 一直在开玩笑
星野结衣 坏笑: 你就只会拿我寻开心。
jump 结束

label 结束
: （AiTalkDemo 播放完毕。四个结果分支、属性联动、倾向统计都看过了。）
